# Mudstuds Utility

Mudstuds Utility is a Gorilla Tag utility mod built with BepInEx, designed for casting and quality-of-life improvements.

## Features

### Casting
- Multiple camera modes
- Freecam
- Smooth camera movement
- Camera presets
- Dolly path support
- Screenshot capture
- Desktop overlay
- HUD customization

### Utility
- Player list
- Teleporter
- Nametag system
- Cosmetic sorting
- Audio controls
- Notification system
- Theme support
- Skybox customization
- Spotify integration
- Video player

### Moderation
- Plugin scanner
- Mod detection
- Known conflict detection
- Player information
- Client redirect support

### Customization
- Custom fonts
- Nametag themes
- HUD customization
- Desktop watermark
- Theme manager
- Icon generation

## Installation

1. Install BepInEx 5.
2. Download the latest release.
3. Place the DLL into:

```
BepInEx/plugins/
```

4. Launch Gorilla Tag.
